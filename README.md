# ONE15 Audio — Clean Deploy

Fresh static build for GitHub + Vercel.

## Important
Upload the **contents of this folder directly to the root of the GitHub repository**.
Do not upload this parent folder as a nested directory.

The repo root should contain:
- `index.html`
- `styles.css`
- `script.js`
- `favicon.ico`
- `assets/`

The hero video is already included at `assets/one15-hero.mp4` and is web-compressed to about 6 MB.

For Vercel:
- Framework Preset: **Other**
- Root Directory: **blank**
- No build command is required.
